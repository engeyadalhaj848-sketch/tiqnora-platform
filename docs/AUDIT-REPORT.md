## 2. ما هو موجود ويعمل (يُحافظ عليه)

- تصميم متجاوب (جوال/تابلت/سطح مكتب) مع حركات reveal
- 15 خدمة ثنائية اللغة مع أسعار وفترات (شهري/مرة واحدة)
- 3 باقات شهرية (الانطلاقة 1490، النمو 2990، التوسع 5990 ر.س)
- سلة طلبات تعمل عبر localStorage مع إرسال بالبريد (mailto)
- لوحة تحكم **محلية فقط** (admin.html): تعديل الخدمات والباقات + استيراد/تصدير JSON — لكن التعديلات تظهر على جهاز واحد فقط
- نموذج تواصل يفتح مسودة بريد إلكتروني
- SEO أساسي: robots.txt, sitemap (الصفحة الرئيسية فقط), canonical, og:title/description/type
- شعار وأصول جاهزة في public/assets

## 3. ما هو مفقود (فجوات حرجة)

1. **قاعدة بيانات:** لا يوجد Supabase مربوط — كل المحتوى ثابت في script.js أو localStorage
2. **مصادقة وأمان:** لا يوجد تسجيل دخول، لا أدوار، لا صلاحيات، لا RLS — لوحة التحكم مكشوفة لأي زائر (admin.html عام)
3. **تجارة إلكترونية:** لا منتجات، لا مخزون، لا طلبات فعلية، لا حسابات عملاء، لا دفع
4. **شحن:** لا توجد أي بنية للشحن أو التتبع
5. **CMS:** لا إدارة للصفحات أو الهيرو أو الصور أو البانرات أو الميتا من اللوحة
6. **وحدات AI:** لا يوجد
7. **سجل نشاط:** لا يوجد

## 4. ما يحتاج تحسينًا

- **Sitemap:** صفحة واحدة فقط — يحتاج كل الصفحات الجديدة
- **Schema:** لا يوجد JSON-LD على الموقع المباشر (Organization, LocalBusiness, Service, Product, FAQ)
- **SEO لغوي:** لا hreflang ولا صفحات /ar و /en منفصلة (اللغة تبديل جانبي فقط)
- **OG:** لا og:image ولا twitter cards
- **الأداء:** جيد حاليًا (موقع خفيف) — يجب الحفاظ عليه
- **GEO:** لا يوجد تحسين لمحركات البحث الذكية (llms.txt, محتوى منظم)

## 5. القرار المعماري

**الحفاظ على البنية الثابتة + ربط Supabase كخلفية كاملة (Backend):**
- الموقع يقرأ المحتوى من Supabase مع fallback للقيم الافتراضية (يعمل حتى لو تعطلت قاعدة البيانات)
- لوحة التحكم تصبح تطبيقًا حقيقيًا: تسجيل دخول عبر Supabase Auth + RLS + إدارة كاملة
- المتجر والطلبات والتتبع تعمل client-side عبر Supabase JS SDK — متوافق 100% مع استضافة Vercel الثابتة
- الشحن ووحدات AI: طبقة Adapter جاهزة للربط بمفاتيح تُدار من إعدادات اللوحة
